# Results

`results/tables/` contains compact machine-readable outputs from the completed development study, including the final design, final metric summary, model validation, operating-envelope comparison, surrogate holdout/CV performance, and optimization workflow counts.

`results/figures/` contains final presentation plots plus selected figures extracted from the original development notebook.

Files prefixed `recomputed_` are regenerated when `scripts/run_final_candidate.py` is run locally after fetching the reference data.
